# Sledeci Kenya Payroll

[![Sponsor](https://img.shields.io/badge/Sponsor-GitHub-ea4aaa?logo=github)](https://github.com/sponsors/kipingor)

Kenyan payroll: employees, payroll runs with PAYE, SHIF, NSSF, Housing Levy and HELB, payslips and P9 export.

## Installation

```bash
composer require sledeci/kenya-payroll
```

Requires `sledeci/core`.
