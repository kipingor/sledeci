# Sledeci Clients

[![Sponsor](https://img.shields.io/badge/Sponsor-GitHub-ea4aaa?logo=github)](https://github.com/sponsors/kipingor)

Client management: profiles, follow-ups and client reports (shows invoices and balances from the accounting package).

## Installation

```bash
composer require sledeci/clients
```

Requires `sledeci/core` and optionally `sledeci/accounting`.
