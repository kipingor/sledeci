# Sledeci Kenya Payments

[![Sponsor](https://img.shields.io/badge/Sponsor-GitHub-ea4aaa?logo=github)](https://github.com/sponsors/kipingor)

Mobile-money collections: M-Pesa (STK push, C2B), Airtel Money and MTN MoMo, with webhook handling.

## Installation

```bash
composer require sledeci/kenya-payments
```

Requires `sledeci/core` + `sledeci/accounting`.
