# Sledeci Kenya Tax (eTIMS)

[![Sponsor](https://img.shields.io/badge/Sponsor-GitHub-ea4aaa?logo=github)](https://github.com/sponsors/kipingor)

KRA eTIMS integration: submit invoices, fetch standard codes, test connection.

## Installation

```bash
composer require sledeci/kenya-tax
```

Requires `sledeci/core` + `sledeci/accounting`.
