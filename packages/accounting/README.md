# Sledeci Accounting

Accounting for the Sledeci suite: chart of accounts, journals, invoices, payments, expenses, financial statements, multi-currency and invoice financing.

## Installation

```bash
composer require sledeci/accounting
```

Requires `sledeci/core`.

## Features

- Chart of accounts & journal entries
- Invoicing with multi-currency / forex
- Payments, expenses, accounting periods
- Invoice financing reports
- PDF generation (dompdf)
- Soft integrations with clients, kenya-tax, kenya-payments

## Frontend

Inertia React pages live under `resources/js/pages/accounting/` and `payments/`.
